# 5차 개선: 독립 평가에서 운영 검증까지

상태: 진행 중. 이슈 #86. 선행 코드 292eb111a99ee7eb2ddff67b65c0e96cda6fa380. LightRAG 미도입.

## 승인된 전체 범위와 증명 조건

1. 새로운 질문·무응답과 원문 근거를 작성·검수하고 평가 파일 해시를 개선 전에 고정한다. 이전 33개 질문 및 동일 의도와 중복을 검사한다. 개발셋과 최종 검증셋은 문서/질문 의도로 분리한다. 같은 작성자가 원문 기반으로 만든 합성 검증은 현장 독립 검증과 구분하며 사람 검수를 대신했다고 주장하지 않는다.
2. 무응답 판정은 개발셋으로만 개선한다. 정상 적중률, 무응답 오탐, 제품·버전·권한 격리, 지연을 함께 측정한다. 검증셋 공개 후 그 결과에 맞춰 튜닝하면 그 세트는 개발용으로 전환하며 새 검증이 필요하다.
3. 원본을 유지하는 후보 생성으로 메뉴와 중복을 제거한다. 제목·절차·표·코드의 보존과 벡터 무효화를 테스트하고 원문/청크 근거 위치를 기록한다. 청킹 전후를 동일 질문으로 비교한다.
4. 실제 장문 다국어 임베딩의 모델/revision/입력/차원을 검증한다. 같은 코퍼스와 평가 조건으로 BM25 및 의미 검색을 비교하고 품질·무응답·비용·지연 근거로 채택한다. 모델명이나 임의 벡터를 실제 추론 결과로 취급하지 않는다.
5. 제품의 실제 답변 경로에서 질문·답변·인용·제품·버전을 평가한다. 문서 적중률과 답변 정확도를 별도 보고한다. 정답 근거 없는 응답과 잘못된 버전 주장은 실패다. 근거 불충분이면 불확실성을 표시한다.
6. 선행 PR과 신규 변경을 검토하고 필수 CI를 통과시킨 후 병합한다. 실제 배포 위치/현재 버전/데이터 권위를 확인하고 검증된 아티팩트를 배포한다. readiness와 실제 검색/답변 read-back을 기록해야 운영 완료다. 기존 서명 승인, 단일 사용 nonce, ACL 및 권위 저장소 게이트는 유지한다.

- 실제 stdio MCP로 16개 결합 질문을 호출해 변경된 프롬프트와 검색 응답을 캡처했다. `mcp-client-korean-development.json`은 실제 도구 응답이며 최종 답변 생성 결과는 아니다. 관련 MCP 표면/프롬프트 18테스트 통과.

## 선택 절차 고정

- E5 개발 비교와 sealed holdout 공개 전에 `development-selection-policy.json`으로 선택 조건을 고정했다. 기존 적중률 95%, 영어 개발/클라이언트 번역 한국어 각 90%, 세트별 무응답 오탐 10% 이하, 금지 소스 0을 요구한다. 통과 후보 중 최저 적중률, 평균 MRR, p95 순으로 비교한다. 한국어 원문 단독 성능은 별도 공개하며 자동 번역 서버 성능으로 바꾸어 보고하지 않는다.
- 번역 포함 한국어 개발에서 구조 BM25도 11/12, 무응답 0/4, MRR .7389였다. MiniLM hybrid의 같은 입력 MRR .5792보다 높다. E5 완료 전 채택하지 않는다.
- 완료된 E5 파일에 전체 모델 read-back을 먼저 실행하고, 같은 네 개발 fixture로 dense/hybrid/RRF를 순서대로 평가하는 일회 실행 작업을 시작했다. 해당 작업은 현재 확인한 임베딩 PID만 관찰하며 후보 없이 종료되면 중단한다. 모델을 재시작하거나 holdout에 접근하지 않는다.

## 최종 후보 검증 실패 및 후속 개선

- E5 39,789청크 전체 생성 및 4위치 실제 재계산 검증 완료. 후보 SHA `ff1118e44d4c1f21e7e465f6e1d66fcb0f4a08a09e9f1f7fbc098054c3febfa0`. 전체 원문/메타데이터·벡터 공간·정규화 검증 통과. 모델/revision은 readback 보고서에 고정돼 있다.
- 고정 선택 규칙으로 BM25를 후보로 선택하고 0ae2c2c에서 평가 전에 기록했다. 세 적격 후보의 최소 적중률 .9167은 같았고 평균 MRR은 BM25 .7598, E5 hybrid .6741, MiniLM hybrid .6159였다. BM25의 기존 20/21 회귀는 숨기지 않았다.
