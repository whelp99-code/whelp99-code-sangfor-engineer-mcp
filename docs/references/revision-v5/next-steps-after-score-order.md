# 점수 필터·정렬 분리 후 다음 진행 계획

관련 작업: GitHub Issue #86, PR #87. LightRAG는 도입하지 않는다.

현재 변경은 선택 가능한 정렬 정책이며 최종 품질 승인이나 운영 활성화가 아니다. 기존 21개 양성 질문의 저장된 실제 모델 점수를 재평가하면, 점수 하한 3/3.5/4에서 모델 정렬은 19/21, 검색 순서 또는 RRF 결합 정렬은 20/21이다. 이는 개발 평가이며 새 보류 평가 성적이 아니다.

1. 네 개발 평가군의 전체 후보 점수를 확보한다. 기존 질문과 영어 평가 실행은 완료되었고, 번역 한국어 개발군 및 과거 공개된 보류 평가군의 전체 점수 수집이 남아 있다.
2. selection-policy-v2에 따라 점수 하한과 정렬을 함께 선택한다. 기존 질문 Hit@5 95% 이상, 나머지 각 평가군 90% 이상, 각 무응답 오탐률 10% 이하와 금지 출처 0건을 유지한다. 적격 설정이 없으면 실패를 기록하고 개발 단계에서 개선한다.
3. 실제 제품 검색 경로에서 선택 설정을 검증한다. 모델 장애·불완전 응답이 정상 무응답으로 표시되지 않는지 확인한다. 응답 시간과 자원 사용량도 기록한다.
4. 설정과 구현을 고정한 후 미사용 holdout-2를 평가한다. 평가 후 기준이나 정답을 바꾸어 통과시키지 않는다. 동일 작성자의 합성 질문이라는 한계도 명시한다.
5. 실제 생성 답변의 근거·인용·제품 및 버전 일치·정보 부족 시 답변 보류를 검증한다. 검색 적중률만으로 답변 정확도를 주장하지 않는다.
6. 최종 변경의 CI와 리뷰를 확인하고 누적 PR을 순서대로 병합한 뒤 BLRO 운영 적용 및 실제 읽기 검증을 진행한다. 외부 자동 리뷰의 미실행은 통과로 기록하지 않는다.

이번 커밋 검증: 관련 4개 테스트 파일 38개 통과, 타입 검사 통과. 최초 테스트 실행은 임시 저장소 쓰기 오류(-122)로 시작하지 못했으며, TMPDIR=/dev/shm으로 재실행하여 통과했다. 전체 CI와 최종 품질 평가는 별도 확인 대상이다.
